# P3 输出复核包

48 次运行产生 **12 个内容完全相同可合并的输出包**，独立人工评审仍为 0。合并条件是整个 packet 的 SHA-256 相同，包括 case/rubric、最终回答、实际送入模型的证据、停止状态与错误；仅文本看似相同不合并。

- `blind-packets.json` 随机排列 12 个唯一包，包含完整材料与待填写的 5 项判据：事实正确、事实完整、主张有证据支持、引用完整、完成用户任务。没有模型或实验组字段。
- `operator-key.json` 将全部 48 次 trial 映射到 packet；只供操作者保管，不交给盲评者。仓库文件权限并不提供物理盲法，需要实际分开交付。
- `progress.json` 与 `manifest.json` 记录导出时的状态、源数据哈希和文件校验值。填写后另存新的 reviewed 文件及版本，不覆盖原始包。

`status=human_reviewed` 必须附 reviewer、逐项布尔判断和理由；模型建议只能保持 `model_provisional`。相同包可复用一次完整评审，但不能增加独立 family 数。无最终输出的包仍保留；正常结束也不等于答案正确。

这些题已经用于开发。审阅能够补充诊断质量，却不能使它们重新成为未见盲测，也不能自动完成 P2 judge 校准。使用 [P2 输出评分接口](../../../src/arkb/evaluation/outputs.py) 绑定原 packet 复算，重新记录报告的标签版本与适用范围。
