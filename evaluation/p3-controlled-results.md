# P3：候选检索、停止策略与 core 建设

2026-09-10（America/Los_Angeles）。**P3 的工程部分和首轮受控开发实验完成；300 个独立需求的人工 core、validation/test 质量结论仍未完成。** 本轮给出了可重算的拒绝/证据不足判断，以及下一步有具体失败证据支持的优化方向。没有将候选配置推广为新的产品默认值。

## 本轮结论

1. **本轮拒绝仅将每路候选 20 扩到 40 的提案。** 新证据进入了原始候选，但在固定 20 个融合候选处丢失；最终 top-10 的 family 平均证据覆盖变化为 0。
2. **固定候选重排的整体收益证据不足。** family 加权变化 +0.32 点，95% CI 为 −4.81 至 +5.13 点。三个桥接变体失去必要服务链接，且同属一个需求族；应优先测试桥接证据保留。
3. **提醒开关没有解决本轮停止失败。** 两组各 24 次运行，均 14 次 final、10 次 max_turns，平均执行 5 次工具。提醒只在一个问题的两次 trial 中触发；这一有限暴露不能证明提醒普遍有效或无效。
4. **core 缺口已成为可检查的入库任务。** 60 queries / 31 个待审需求族，已确认独立性 0；距 300 个候选族还差 269 个，全部仍需审阅。58 篇语料距当前 core 起步目标 300 篇还差 242 篇。

## 预注册与可复核范围

[协议](experiments/p3-protocol.json) 在任何本轮模型结果产生前冻结。结果：46 个检索 query × 4 配置 = **184 条 component 记录**；12 个 Agent query / 10 families × 2 配置 × 2 trials = **48 条 Agent 记录**。无缺失、重复行或运行错误；Agent 的 20 次 max_turns 仍计入执行失败。

- 所有题来自已经用于 P1/P2 开发的 provisional pilot，manifest SHA-256 为 `aebb441dd068b5b0335d031afc5c4900b8acbe819198612355d2866ff816c3d7`。没有伪造新的 blind split。
- 检索使用冻结语料、chunk 配置与 embedding；在 Qdrant `exact=True` 下各取 BM25 / semantic top-40，冻结后派生 10/20/40 前缀。此设计控制 ANN 候选波动，不是线上 ANN 深度或延迟评估。
- 每路深度是候选实验的唯一变量。RRF=60、融合池=20、返回=10 固定。重排只作用于 depth20 的同一批 20 个融合候选，保留每个输入、浮点分数和输出排序。
- 停止实验使用同一默认 4B、thinking=true、temperature=0、最多 8 轮。只切换 `search_stall_reminder`；初始提示和工具定义一致。每题第二个 trial 交换首跑组，第二轮倒序运行题目；模型推理串行，均为全新对话。
- 两组预算相同：12 次工具、10 次 query（match/search）、6 次 read、累计 4,000 个证据 tokens、120 秒协作式截止。未触发预算停止；同步请求仍无法被硬取消。
- 冻结源码、协议、语料、模型 digest、reranker 实际文件哈希、reference tokenizer、SQLite 和全部向量前后校验通过。原始实验开始于 2026-09-11 00:15:56 UTC，结束于 00:29:07 UTC，对应本地 9 月 10 日。

## 候选与重排结果

下表是 **case 平均**草稿证据覆盖，43 个有证据定义的 query；3 个缺口问题的空分母保持 null。

| 配置 | 原始候选并集 | 固定融合池 | 最终 top-10 |
| --- | ---: | ---: | ---: |
| depth10 | 87.21% | 87.21% | 87.21% |
| depth20 | 95.35% | 95.35% | 84.88% |
| depth40 | 98.84% | 95.35% | 84.88% |
| depth20 + rerank | 95.35% | 95.35% | 81.40% |

正式配对统计先平均同题 trial，再平均同族 case，最后对 **26 个 family** 等权；固定 seed=20260910，10,000 次整族 bootstrap。预注册开发效果门槛为最终证据覆盖提升 3 点。

| 对照 → 干预 | family 平均覆盖 | 差值及 95% CI（百分点） | 族级胜/平/负 | 本轮判断 |
| --- | --- | --- | --- | --- |
| depth20 → depth40（主比较） | 91.99% → 91.99% | 0.00 [0.00, 0.00] | 0 / 26 / 0 | 拒绝本轮加深提案 |
| depth10 → depth20（次比较） | 93.27% → 91.99% | −1.28 [−3.85, 0.00] | 0 / 25 / 1 | 未达到开发提升门槛 |
| depth20 → rerank（次比较） | 91.99% → 92.31% | +0.32 [−4.81, +5.13] | 2 / 23 / 1 | 证据不足 |

所有 family 配对差值恰为零时，经验 bootstrap 会退化成 [0,0]；它只反映这批观测，不能证明总体等效。次比较区间未做多重比较校正。草稿标签、已见题目和稀疏 qrels 也不支持生产优越性结论。

重排后的 source nDCG@10 从 0.8467 升到 0.8804，但 case 平均完整证据覆盖下降。source 排名无法保证关键片段或多跳组合保留；这是同时保留分阶段证据指标的实际价值。这里的 source 排名是在 top-10 chunks 内折叠来源，并非补齐 10 篇文档。Assessed@10 约 13%–14%，且标签仍为草稿，不作为充分人工判断的排名质量结论。

### 可定位的丢失点

[离线归因记录](audits/20260910-p3-attribution.json) 保留逐 facet 首次完整覆盖所需排名与每个候选的重排前后位置：

- `pilot_007`：增加到 depth40 才取得所需 facet，首次完整覆盖在融合排序 **第 22 位**；被 20 候选上限截断。
- `pilot_013`：一个 facet 首次完整覆盖在 **第 33 位**，同样未进入 20 候选池。它在 Agent track 中允许不同 query 和 read，不能把固定 query 的失败直接解释为 Agent 必然缺证据。
- `pilot_040/041/042`：服务桥接文档从输入第 **1/2/2 位**跌到重排 **第 13 位**，排出返回 top-10；当前政策文档仍排第 2，旧版本文档排第 1。多跳联合证据因此从完整变为不完整。这三个问题属于一个合成需求族。
- `pilot_024` 的重排覆盖由 0.5 升到 1，`pilot_055` 由 0 升到 1，说明重排也有可观察的局部收益。

使用同一 pinned reranker tokenizer 检查全部 **920 个 query-document pair**：实际模板后的正文输入预算为 464 tokens，最长 pair 302，**0 个被截断**。因此本轮桥接丢失不能归因于 512 长度上限；评分/选择策略是更直接的后续实验对象。长度检查不是模型注意力解释，也不能证明其他语料无截断问题。

本轮实际 reranker scorer 总耗时约 101.84 秒；共享候选只检索一次，所以没有为各前缀组伪造独立延迟或成本。线上成本仍需另行实测。

## 停止实验

| 指标（trial 平均/计数） | 提醒开启 | 提醒关闭 |
| --- | ---: | ---: |
| trials / queries / families | 24 / 12 / 10 | 24 / 12 / 10 |
| 正常 final | 14 / 24（58.33%） | 14 / 24（58.33%） |
| max_turns | 10 | 10 |
| 运行错误 / 预算停止 | 0 / 0 | 0 / 0 |
| 平均执行工具次数 | 5.00 | 5.00 |
| 证据交付代理指标 | 75.00%（16 个适用 trial） | 75.00%（16 个适用 trial） |
| Agent 原生 output tokens | 853.08 | 848.25 |
| 提醒实际进入模型的运行 | 2 | 0 |
| 人工确认 grounded success | 未知 | 未知 |

证据交付代理指标只对有 facet 的题定义：有效 final 取实际送入模型的覆盖率；执行失败取 0。它不是答案正确率。family 等权的 final 比例均为 55%，工具次数均为 5.05；与表中 trial 平均不同属于权重差异。

两次重复中每题的停止状态与交付包均一致。48 条记录仅有 12 个唯一完整 packet；重复用于检验稳定性，不增加独立样本数量。[盲序输出复核包](reviews/p3-controlled-20260910/README.md) 已导出，人工审阅 0。

五个失败 case 在两组均耗尽轮数：

- `pilot_013`：第 2 次模型请求已取得全部草稿证据，此后仍执行 7 次工具，最终没有输出；现有 search 停滞条件没有触发。
- `pilot_055`：第 6 次模型请求已取得可回答部分的证据，之后又执行 3 次工具，持续寻找语料没有提供的实测节省比例。
- `pilot_053/054`：为未记录的测量/项目持续改写 query；结果变化使“完全无新增 search 证据”的提醒条件未触发。
- `pilot_056`：题目缺少服务身份，提醒两次进入模型上下文，仍搜索到第 8 轮。开启与关闭时都没有交付澄清问题。

“达到标注阈值后的调用”并不自动等于浪费：复核、冲突处理或回答组织仍可能需要工作。这里可确认的是达到草稿阈值后仍未产出结果。观察支持后续测试任务级完成/缺口识别和预算感知的结束策略；不能据此让 gold 参与线上停止。

停止策略结论为 **证据不足，保留当前默认**。未观察到工具节省；输出质量尚未人工确认，预注册的质量非劣门槛无法通过。耗时约 14 秒/次只是本机观察，缓存和负载未受控，原生 usage 仅含 Agent chat，未单列 embedding 开销。

## core 与样本量

[core 入库说明](data/v2/core-intake/README.md) 和 [readiness](data/v2/core-intake/readiness-20260910.json) 已建立。工具支持：来源/作者/许可记录、独立审阅与实际 pool 审计文件绑定、永久开发暴露清单、已知 query 更名检查、整组确定性切分和拒绝覆盖的冻结。

当前 31 个族全部留在 dev；目标缺口 dev 89 / validation 60 / test 120。不能通过翻译、改写或同一模板多造问题填满独立样本配额。尚需新的可使用真实来源、人工独立需求/证据判断，以及未暴露标签的保管者。工具无法认证人的独立性或实现物理盲法。

[功效敏感性分析](audits/20260910-p3-power.json) 模拟独立 family 的二元配对质量结果，使用精确条件双侧二项检验：

| 假设真实提升 | 两系统成败不同的比例 | 120 families 的正向检出率 |
| --- | ---: | ---: |
| 3 点 | 10% | 11.22% |
| 5 点 | 10% | 31.22% |
| 10 点 | 10% | 98.33% |
| 3 点 | 30% | 6.69% |
| 5 点 | 30% | 13.03% |
| 10 点 | 30% | 45.72% |

每格 10,000 次模拟，原始文件给出 Monte Carlo 标准误。这些 discordance 是假设值；没有人工质量配对标签，正式 test 数量仍未选择。该分析说明 300 总量 / 120 test 不是可信度保证，也不替代非劣检验设计。

## 下一轮优化顺序

[决策日志](experiments/p3-decision-ledger.json) 记录本轮比较及零次 validation/test 尝试，所有候选 `production_adoption=false`。

1. 在固定深度下测试**融合池的选择与证据保留**：以 `pilot_007/013` 第 22/33 位的丢失为诊断，不先扩大 embedding 或 Agent 模型。
2. 测试**保留桥接文档的重排/选择策略**：固定相同候选和输出预算，验证 multi-hop 提升以及单跳回归；当前无截断，应优先验证排序与组合选择。
3. 测试**任务完成、缺证据和歧义下的结束策略**：显式区分能回答的部分与缺失事实，使用相同预算并人工比较输出，避免把“更早停止”当成“更好”。
4. 同步补充独立 core gold 和未见 validation/test。上述方向都是尚未测量的新假设，当前结果提供实验依据，尚未实现或确认收益。
